# Contributing to Soapy Panels

Thank you for helping improve Soapy Panels. Contributions may include bug
reports, documentation, translations, tests, designs, and source-code changes.

## Development workflow

1. Create a focused branch from the current development branch.
2. Keep the saved `.soapy` format and documented application contracts
   backward compatible unless a migration has been agreed in advance.
3. Follow `AGENTS.md` and the architecture documents under `docs/`.
4. Add or update the smallest relevant tests.
5. Run the checks described in `AGENTS.md` and include the results with the
   proposed change.

Please do not commit generated build directories, private keys, Store
credentials, personal data, or third-party material whose redistribution and
modification rights are unclear.

the contribution under those terms.

AI-assisted contributions are welcome, but the submitter remains responsible
for reviewing the result and confirming that it does not copy incompatible or
unlicensed material.

## Conduct

Be respectful, specific, and constructive. Harassment, threats, and deliberate
disruption are not welcome in project spaces.
